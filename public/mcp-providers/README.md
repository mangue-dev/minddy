# MCP provider logos

These assets come from the providers’ own websites or brand kits, verified on
September 4, 2026. `sources.json` records the source page, exact asset URL, archive
member where applicable, and verification date for each file. Google Workspace
assets include the updated gradient app icons published after the May 2026 refresh.
Canva uses its icon logo, which its integration guidelines recommend below 50 px.

Files retain the providers’ original colors, proportions and bytes. `BrandLogo`
renders them locally with `object-contain`, without a runtime logo API or remote
image request. The marks identify their respective services; trademark rights
remain with their owners.

When updating a preset or reviewing its branding, revisit the recorded official
source, download its current icon or brand mark, inspect it in both Minddy themes
at the actual display size, and update the provenance and verification date.
Use an official dark-background variant when the mark needs one. Do not replace
multicolor logos with monochrome icon paths or recolor provider assets.
