# Open-source launch announcement

Status: prepared draft. Publish only after MIN-470 confirms every anonymous
public path and MIN-471 authorizes the announcement.

## Long-form announcement

minddy is now open source.

The complete core is available under AGPL-3.0-only: issue tracking, objectives,
project knowledge, feedback, integrations, coding-agent workflows, desktop
applications, and the supported self-hosting path.

- Source and releases: https://github.com/mangue-dev/minddy
- Current release: https://github.com/mangue-dev/minddy/releases/latest
- Self-hosting guide:
  https://github.com/mangue-dev/minddy/blob/main/docs/self-hosting.md
- Container image: https://github.com/mangue-dev/minddy/pkgs/container/minddy
- Contribution guide:
  https://github.com/mangue-dev/minddy/blob/main/CONTRIBUTING.md
- Confidential security reporting:
  https://github.com/mangue-dev/minddy/security/policy
- Community support: https://github.com/mangue-dev/minddy/discussions
- Minddy Cloud: https://www.minddy.app

Self-hosted minddy is the same public core operated on infrastructure you
control. Minddy Cloud is the managed option. The edition guide explains the
differences in responsibility, data flow, providers, backups, and support:
https://github.com/mangue-dev/minddy/blob/main/docs/editions.md

We welcome reproducible bug reports, focused proposals, and signed-off pull
requests. Please read the contribution and security policies before sharing
code or logs.

## Short announcement

minddy is now open source under AGPL-3.0-only: source, releases, self-hosting,
desktop apps, and contribution paths are available at
https://github.com/mangue-dev/minddy. Minddy Cloud remains the managed option.
