## Corrections and clarifications

- `filterList`: the slash shortcut focuses a visible sidebar filter, rather
  than filtering every screen. Triage and code review are examples of screens
  with that field (`components/sidebar-filter-field.tsx:42`). Keep the routine's
  narrower wording.
- `undo`: issue edits, moves, and deletions participate in local undo history;
  server-side agent changes do not (`lib/undo/undo-context.tsx:3`). Keep the
  wording scoped to issue changes rather than promising to undo every mistake.
- `newObjective`: the creation shortcut works outside project screens too,
  with a project picker (`lib/create-context.tsx:319`). Keep the app-wide wording.
- `sidebarVisibility`: the visibility button is in the top-left app bar,
  and hidden navigation returns from the left-edge hover area
  (`components/app-top-bar.tsx:31`, `components/sidebar-nav-overlay.tsx:220`).
  Keep the updated location and the formal German address.

## Added tip

`tabSwitch` uses `nav.numberedTab` from CHEATSHEET. Numbered navigation requires
modifiers, addresses only the first ten tabs, and includes pinned and overflow
tabs (`lib/keyboard/navigation-shortcuts.ts:9`). Replace the routine's claim
that typing a tab's number is sufficient with:

- English: “Switch to one of the first ten open tabs with the numbered keyboard shortcut.”
- French: the equivalent localized message in `messages/fr.json`, under `Home.tips.tabSwitch`.

The rendered key badges supply the exact chord. Update the other four locales
with the same scope, without hardcoding keys or introducing placeholders.
