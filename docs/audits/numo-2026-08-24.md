# Audit Numo — 2026-08-24

## Blocking

- The PR context was produced by the UI (`components/pull-requests/pull-requests-page.tsx:609-621`) and declared in `AssistantPageContext` (`lib/assistant-types.ts:157-162`), but `parsePageContext` did not copy it (`app/api/assistant/chat/route.ts:127-151`). Numo therefore lost the PR number, state and run as soon as chat input reached the API. The parser now preserves and validates these three fields.

## Drift

- `propose_backlog` rejected non-owners (`lib/server/assistant/execute-tool.ts:951-957`) without declaring that restriction (`lib/server/assistant/tools.ts:398-411`). Its description now says `OWNER ONLY`.
- `add_feedback_comment` advertised a 1,000-character limit and no headings (`lib/server/assistant/tools.ts:1095-1108`), while the shared service truncates at 65,536 characters and does not filter headings (`lib/server/add-comment.ts:391-416`). The description now reflects the actual behavior without changing the shared service.
- The application supports PR actions (merge, close, reopen, review and comments) through `app/api/pull-requests/[prId]/route.ts:60-87` and `app/api/pull-requests/[prId]/comments/route.ts:21-28`, while Numo exposes only reading and linking (`lib/server/assistant/tools.ts:1966-2006`). The read tool previously implied that it could review a PR (`lib/server/assistant/tools.ts:1968-1970`); its description now limits it to explaining the PR and its review feedback, and points code changes to `launch_code_agent`. Extending direct PR actions should be handled separately because it requires permission and confirmation design.
- The application supports wiki files, duplication, comments and public sharing in `app/api/projects/[id]/pages/[pageId]/files/route.ts:13-28`, `duplicate/route.ts:11-20`, `comments/route.ts:13-24` and `share/route.ts:13-21`, while Numo only covers page reading and editing (`lib/server/assistant/tools.ts:540-703`). Extension should be planned with the corresponding permission rules.
- Editable account and project settings exceed the Numo tools: automations, BYOK keys, `send_mode`, Git, import and icon (`components/settings/account-automations-section.tsx:129-180`, `account-ai-keys-section.tsx:151-175`, `account-preferences-section.tsx:179-197`, `project-git-section.tsx:170-218`, `project-import-section.tsx:23-33`, `project-general-section.tsx:190-201`). Numo contracts currently cover only part of these settings (`lib/server/assistant/tools.ts:1349-1494`, `1141-1200`). No additions were made because each new setting requires an explicit security and scope decision.
