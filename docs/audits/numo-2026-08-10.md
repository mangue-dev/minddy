# Audit Numo — 2026-08-10

## Drift

### Smart-fill for ticket creation

Numo could create a ticket and ask the application to deduct priority,
effort, categories and goal via Smart-fill, but could neither read nor
change the account setting that enables this feature. The setting is
exposed in `components/settings/account-preferences-section.tsx:111-124` and
its definition is `lib/smart-fill.ts:21-28`, while the core settings
account did not return it (`lib/server/account-settings.ts:139-155`).

Fix: `get_account_settings` now returns `smart_fill` and
`update_account_settings` validates and writes it; the field is exposed in
`lib/server/assistant/tools.ts:1112-1120`. The field of creation is also
exposed in `lib/server/assistant/tools.ts:98-106`, then transmitted by
`lib/server/assistant/execute-tool.ts:831-844` at the heart of creation.

### Traduction des retours du board

The project settings already allowed you to activate the translation, choose the
team language and manage languages without translation in
`components/feedback/feedback-settings-shared.tsx:537-648`. The heart called by
the tool also accepted these fields in `lib/server/update-project.ts:89-105`,
but the `update_project` scheme did not expose them (`lib/server/assistant/tools.ts:875-923`).

Correction: addition of the three fields to the Numo schema, with descriptions and
Explicit replacement semantics for the list.
