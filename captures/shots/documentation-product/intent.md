# Documentation product controls

Capture actual candidate application controls in the six article languages.
Use the existing guarded demo account and local candidate, never a documentation
preview as product evidence. Translate only exact seeded prose in GET responses
using `localized-fixture.json`; preserve identifiers, states, relationships,
structure, timestamps and mentions. Do not submit content, membership, sharing,
restore, purge, or account forms. Navigation may persist application tabs.

Record the commit, locale, theme, route, control, adaptation and network writes.
Candidates require visual review and exact article mapping before publication.
An open control proves that state was visible; it does not prove that a save,
publication, restore, import or release action completed.
