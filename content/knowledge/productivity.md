Saved views filter and sort issues while the kanban board remains grouped by status. A personal cross-project view lets a user see work across projects. The cycle is a personal weekly or fortnightly planning surface that can include issues from multiple projects. It is distinct from a project objective.

Routines are scheduled instructions that run on a project and use the owner's AI budget. Personal statistics give each user a view of completed issues, pace, and time spent, with breakdowns by project, category, and objective. The task notebook is a private, optional scratchpad for quick notes and checkboxes before they become issues. A notebook note can be promoted into an issue when it grows into work that the project should track.
