minddy is open source. Its canonical source repository is github.com/mangue-dev/minddy and it is released under the GNU AGPL v3.0 only. People can inspect the application code, release process, security model, and self-hosting documentation; bugs and improvements belong in the repository's issue forms and discussions, with pull requests following the contribution guide.

minddy can run on infrastructure the operator controls. The documented self-hosting path covers a reproducible installation, operations, upgrades, backups, recovery, and release acceptance. Managed cloud services such as billing and managed AI are not self-hosting prerequisites: an operator configures the integrations and AI provider they choose. The license and naming policy remain applicable to modified or hosted deployments.
