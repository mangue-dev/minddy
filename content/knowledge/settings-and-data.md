Project owners manage project settings, members, categories, integrations, feedback boards, and project automations. Account settings belong only to the current user and include identity, interface language, personal preferences, notifications, and code-agent defaults. A project member can work on issues and categories according to the available product permissions, but cannot change owner-only settings.

minddy does not sell data or use it for advertising. Users can request an export or deletion through the support contact. Repository access tokens are encrypted before storage and are used only when a user triggers an action that needs the connected repository.
