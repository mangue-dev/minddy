minddy is available in the browser and as a desktop app for macOS, Windows, and Linux, with native notifications and a server picker with three destinations: Minddy Cloud, a self-hosted server origin, or a local minddy runtime on the computer. Updates are automatic on macOS and the portable Linux AppImage; Windows updates come from the Microsoft Store, and the deb/rpm Linux packages are updated by installing the next verified release. Closing the window hides it and keeps minddy running on every platform; on macOS, quitting the app (Cmd+Q) ends it. The command palette provides keyboard-first access to search, creation, and common changes.

Voice dictation can fill issue fields and is also available in places such as comments and instructions to Numo. Existing backlogs can be imported from CSV exports: Linear and Jira layouts are detected automatically, and any other CSV imports through generic column mapping with assistance from Numo. Import is optional and can be done during setup or later from project settings.
