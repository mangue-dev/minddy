minddy is available in the browser and as a desktop app for macOS, Windows, and Linux, with automatic updates, native notifications, and a server picker that chooses between Minddy Cloud and a self-hosted instance. On Windows and Linux, closing the window keeps minddy running in the background. The command palette provides keyboard-first access to search, creation, and common changes.

Voice dictation can fill issue fields and is also available in places such as comments and instructions to Numo. Existing backlogs can be imported from CSV exports, including exports from tools such as Linear, Jira, Trello, Notion, and GitHub. Import is optional and can be done during setup or later from project settings.
