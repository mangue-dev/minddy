minddy Cloud has Free, Go, and Pro plans. Every plan includes the MCP server, Numo conversations, contextual actions, and routines. Plans differ in workspace capacity, included AI usage, available models, and storage; use the current account information or pricing page for exact values instead of inventing a limit.

Included usage covers Numo's work and the other AI features: conversation reasoning and Minddy tool calls, routines, automation steps, voice dictation, and feedback processing. The billing page splits consumption into Routines, Numo, Voice dictation, Feedback, and Automations. Coding agents the user runs outside minddy and connects through MCP use their own subscription or API account, not minddy's included usage. When the monthly budget or a routine's per-run cap is reached, that AI work pauses without an automatic overage charge; completed work remains in the conversation.

Users can connect several compatible personal API keys and assign text, transcription, and embedding calls to different providers. They can also choose which AI surfaces use each key: Numo conversations and comments, automations, voice dictation, and feedback processing. The assigned provider bills compatible model calls made with that key, so those calls do not count against minddy's included AI usage. Model types without an assignment, surfaces a key does not cover, and accounts without a key stay on the minddy service and its plan usage.
