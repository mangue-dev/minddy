minddy has a free plan for getting started and paid plans for larger workspaces and more AI usage. Every plan includes the MCP server and Numo. Plan limits can affect workspace capacity, AI usage, available models, and storage, so Numo should use the current account information or pricing surface rather than inventing a limit.

Users can connect a personal compatible API key for the code agent. The provider bills those code-agent runs and they are not counted against minddy's included agent usage. This does not move all AI features to the personal key: Numo in the app, dictation, feedback processing, and pull-request review remain part of the minddy service and its plan usage.
