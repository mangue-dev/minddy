minddy Cloud has Free, Go, and Pro plans. Every plan includes the MCP server, Numo conversations, contextual actions, delegated code work, and routines. Plans differ in workspace capacity, included AI usage, available models, and storage; use the current account information or pricing page for exact values instead of inventing a limit.

Included usage covers the complete Numo operation: conversation reasoning, Minddy tool calls, automation steps, delegated code-worker model calls, and server-sandbox compute. When the monthly budget or a routine's per-run cap is reached, that AI work pauses without an automatic overage charge; completed work remains in the conversation.

Users can connect a compatible personal API key and choose which AI surfaces use it: Numo conversations, delegated code work, automations, voice dictation, and feedback review. The provider bills compatible model calls made with that key, so those calls do not count against minddy's included AI usage. Server-sandbox compute still uses the included budget. Surfaces the key does not cover, and accounts without a key, stay on the minddy service and its plan usage.
